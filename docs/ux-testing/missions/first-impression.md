# Uppdrag: förstå Matrundan

## Start

Öppna den publika landningen som en ny användare utan konto.

## Situation

En vän har nämnt Matrundan men inte förklarat vad tjänsten gör. Ta reda på om appen verkar relevant för en grupp som vill äta tillsammans.

## Mål

Förklara med egna ord:

- vad Matrundan är till för;
- vem informationen delas med;
- vad gruppen kan göra före och efter ett besök;
- vilket nästa steg du själv skulle välja.

Utforska exempelgruppen om det känns som den naturliga vägen.

## Slutvillkor

Uppdraget är klart när du kan beskriva produkten och har valt om du skulle fortsätta, skapa konto eller lämna.

## Särskilt att observera

- första synliga handling;
- om exempelgruppen uppfattas som säker att prova;
- om appen misstolkas som publik restaurangkatalog eller individuell dagbok;
- ord eller symboler som behöver förklaring.
