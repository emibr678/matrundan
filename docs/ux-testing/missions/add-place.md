# Uppdrag: lägg till ett matställe

## Start

Öppna en aktiv grupps sida Matställen på mobil.

## Situation

Du och två vänner pratade om ett matställe som gruppen ännu inte har sparat. Försök hitta och lägga till det så att gruppen kan välja det senare.

## Mål

Hitta ett relevant resultat, bedöm att det är rätt verksamhet och lägg till det i gruppens lista. Om du ser flera intressanta resultat får du försöka spara fler än ett.

## Slutvillkor

Uppdraget är klart när det valda stället går att hitta bland gruppens ställen och du förstår hur du återgår till sökningen.

## Särskilt att observera

- skillnaden mellan sökning i gruppens lista och sökning efter nya ställen;
- lista kontra karta;
- sökområden och radie;
- redan tillagda, tidigare borttagna eller dolda träffar;
- enkelval kontra flerval;
- beteendet för Tillbaka, kryss och mobilens eget bakåtkommando;
- vad saknad webbplats eller öppettider verkar betyda.
