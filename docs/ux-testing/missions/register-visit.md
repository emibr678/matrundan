# Uppdrag: registrera ett verkligt besök

## Start

Öppna detaljsidan för ett matställe som gruppen nyligen besökte.

## Situation

Tre personer i gruppen åt där i går. Du ska dokumentera besöket så att historiken och deltagarnas progression blir riktig.

## Mål

Registrera datum, måltid, faktiska deltagare och ett helhetsomdöme. Lägg till kommentar eller foto om det känns naturligt och kontrollera därefter hur besöket visas.

## Slutvillkor

Uppdraget är klart när besöket finns i historiken och du kan förklara vilka personer som fick besöket tillgodoräknat.

## Särskilt att observera

- om registreraren antas vara deltagare automatiskt;
- om externa deltagare förstås;
- vilka fält som uppfattas som obligatoriska;
- hur privat foto och kommentar uppfattas;
- om besöksdetaljen går att hitta igen;
- skillnaden mellan eget och delat besök;
- möjlighet att rätta eller ta bort felregistrering.
